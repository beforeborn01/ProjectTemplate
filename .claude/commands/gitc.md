# Git 智能提交

自动查看 git 修改，分析变更内容，生成合适的提交信息并执行提交。

## 执行步骤：

1. **查看当前状态**：
   - 运行 `git status` 查看所有未跟踪和已修改的文件
   - 运行 `git diff` 查看未暂存的变更
   - 运行 `git diff --staged` 查看已暂存的变更

2. **分析变更内容**：
   - 分析所有变更的代码内容和文件类型
   - 理解变更的业务目的和技术意图
   - 识别变更的性质（新功能、bug修复、重构、配置变更等）

3. **生成提交信息**：
   - 根据变更内容生成简洁明了的中文提交信息
   - 提交信息格式应遵循项目约定：
     - 第一行：简洁的变更摘要（50字符以内）
     - 如需要，空一行后添加详细说明
   - 确保提交信息准确反映变更的"原因"而不只是"内容"

4. **执行提交**：
   - 如有未暂存的变更，先执行 `git add .` 添加所有变更
   - 使用生成的提交信息执行 `git commit`
   - 确认提交成功

5. **验证结果**：
   - 运行 `git log --oneline -1` 显示最新提交
   - 运行 `git status` 确认工作区干净

## 注意事项：
- 如果没有变更需要提交，提示用户当前工作区是干净的
- 如果发现敏感信息（如密码、API密钥），警告用户不要提交
- 提交信息应该使用中文，符合项目的提交信息风格
- 在提交前会显示即将提交的内容供用户确认

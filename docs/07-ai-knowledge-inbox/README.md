# AI 知识草稿 (AI Knowledge Drafts)

本目录用于存放 AI 根据会话内容自动总结的知识点。

## 使用流程
1. **待确认**：AI 生成的原始知识文件存放在本目录下。
2. **人工审核**：开发者阅读并确认知识的准确性。
3. **归档**：
   - 如果确认无误，将其移动到 `docs/` 下对应的正式目录（如 `02-architecture` 或 `03-design`）。
   - 如果不准确，进行修改或删除。

## 命名规范
- 每个知识点独立成文。
- 建议使用日期和简短描述命名，例如：`2024-03-11-caching-strategy.md`。
